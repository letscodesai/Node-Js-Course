Practice 1: REST API with Node.js

Football Team Management.

Build a REST API with Node.js, Express.js and MySQL to manage the players of a football team.

Node.jsExpress.jsMySQLmysql2

1Problem Description

You are given a file app.js and a MySQL database named football_practice_db, which consists of a table football_team.

Write APIs to perform operations on the football_team table containing the following columns:

ColumnType
player_idINTEGER (Primary Key, Auto Increment)
player_nameVARCHAR(100)
jersey_numberINTEGER
positionVARCHAR(50)

Note: The table columns use snake_case (for example player_name), but the API requests and responses use camelCase (for example playerName).

2Instructions

  • Use MySQL as the database.
  • Use the mysql2 package to connect MySQL with Node.js.
  • Use Express.js to create the APIs.
  • Use npm install to install the required packages.
  • Export the Express instance using the default export syntax.
  • Use SQL queries to perform all database operations.

3API Specifications

API 1GET/players/

Description: Returns a list of all players in the football team.

Response

JSON
[
  {
    "playerId": 1,
    "playerName": "Lionel Messi",
    "jerseyNumber": 10,
    "position": "Forward"
  },
  {
    "playerId": 2,
    "playerName": "Cristiano Ronaldo",
    "jerseyNumber": 7,
    "position": "Forward"
  }
]
API 2POST/players/

Description: Creates a new player in the football team (database). player_id should be auto-incremented.

Request

JSON
{
  "playerName": "Neymar Jr",
  "jerseyNumber": 11,
  "position": "Forward"
}

Response

Text
Player Added to Team
API 3GET/players/:playerId/

Description: Returns a player based on a player ID.

Response

JSON
{
  "playerId": 1,
  "playerName": "Lionel Messi",
  "jerseyNumber": 10,
  "position": "Forward"
}
API 4PUT/players/:playerId/

Description: Updates the details of a player in the football team (database) based on the player ID.

Request

JSON
{
  "playerName": "Kylian Mbappe",
  "jerseyNumber": 9,
  "position": "Forward"
}

Response

Text
Player Details Updated
API 5DELETE/players/:playerId/

Description: Deletes a player from the football team (database) based on the player ID.

Response

Text
Player Removed

4Database Setup

Follow these steps to create the database:

  1. Open MySQL Workbench.
  2. Create a new SQL query tab.
  3. Copy and paste the entire script given below.
  4. Execute the script.
football_practice_db.sql
-- Create database
CREATE DATABASE IF NOT EXISTS football_practice_db;

-- Select database
USE football_practice_db;

-- Create table
CREATE TABLE IF NOT EXISTS football_team (
    player_id INT AUTO_INCREMENT PRIMARY KEY,
    player_name VARCHAR(100),
    jersey_number INT,
    position VARCHAR(50)
);

-- Insert sample football players
INSERT INTO football_team (player_name, jersey_number, position)
VALUES
    ('Lionel Messi', 10, 'Forward'),
    ('Cristiano Ronaldo', 7, 'Forward'),
    ('Kylian Mbappe', 9, 'Forward'),
    ('Kevin De Bruyne', 17, 'Midfielder'),
    ('Luka Modric', 10, 'Midfielder'),
    ('Virgil van Dijk', 4, 'Defender'),
    ('Sergio Ramos', 15, 'Defender'),
    ('Alisson Becker', 1, 'Goalkeeper'),
    ('Erling Haaland', 9, 'Forward'),
    ('Jude Bellingham', 5, 'Midfielder');

-- Display all players
SELECT * FROM football_team;

Important: Run the script only once to avoid duplicate records. To start fresh, execute DROP DATABASE football_practice_db; and then run the complete script again.

5How to Test Your APIs

Create an HTTP file (for example test.http) in your project and write one request for each endpoint listed below. Send the requests in the given order and check the points mentioned for each one. Change the port in the URL if your server runs on a different one.

RequestURLWhat to check
GET http://localhost:3000/players/
  • Status is 200 OK.
  • The response is an array with all the players.
  • Keys are in camelCase: playerId, playerName, jerseyNumber, position.
POST http://localhost:3000/players/
  • Send the JSON request body given in API 2 with the header Content-Type: application/json.
  • The response text is exactly Player Added to Team.
  • Send the GET request for all players again. The new player appears at the end of the list with an auto-generated ID.
GET http://localhost:3000/players/1/
  • The response is a single object (not an array).
  • It shows Lionel Messi with the correct keys and values.
  • Change the ID in the URL and check that the matching player is returned.
PUT http://localhost:3000/players/3/
  • Send the JSON request body given in API 4 with the header Content-Type: application/json.
  • The response text is exactly Player Details Updated.
  • Send the GET request for player 3 again. The details now match the request body.
  • No other player has changed.
DELETE http://localhost:3000/players/10/
  • The response text is exactly Player Removed.
  • Send the GET request for all players again. Player 10 is no longer in the list.

Tip: Running the requests again changes the data (a new ID is generated and the deleted player no longer exists). To start from the original data, drop the database and run the SQL script again.
